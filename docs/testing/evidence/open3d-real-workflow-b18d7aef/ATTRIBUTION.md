# Dataset attribution

The image depicts a reconstruction made from **Open3D DemoICPPointClouds**, three fragments from the **living-room1 scene of the Redwood RGB-D dataset**, distributed by Open3D in its [20220301-data release](https://github.com/isl-org/open3d_downloads/releases/tag/20220301-data).

The dataset-specific grant is **[Creative Commons Attribution 3.0 Unported](https://creativecommons.org/licenses/by/3.0/)**, as stated by Open3D for [DemoICPPointClouds](https://www.open3d.org/docs/release/cpp_api/classopen3d_1_1data_1_1_demo_i_c_p_point_clouds.html). The [frozen upstream dataset declaration](https://github.com/isl-org/Open3D/blob/b6c5e196384ad71e75b6e6f9c5da22d046221f1d/cpp/open3d/data/Dataset.h) supplies the same grant. The [Open3D data tutorial](https://open3d.org/docs/latest/tutorial/data/index.html#demoicppointclouds) identifies the Redwood scene. Credit: Sungjoon Choi, Qian-Yi Zhou and Vladlen Koltun, *Robust Reconstruction of Indoor Scenes*, CVPR 2015; Ankur Handa, Thomas Whelan, John B. McDonald and Andrew J. Davison, *A Benchmark for RGB-D Visual Odometry, 3D Reconstruction and SLAM*, ICRA 2014; and the Open3D project. No endorsement is implied.

The [Redwood dataset description](https://redwood-data.org/indoor/dataset.html) identifies living-room1 as part of the augmented ICL-NUIM synthetic indoor dataset and requests both papers above be credited. The [original ICL-NUIM author page](https://www.doc.ic.ac.uk/~ahanda/VaFRIC/iclnuim.html) independently states CC BY3.0. This is a real execution on synthetic benchmark input; it is not a new physical sensor capture.

Changes: the original fragments were registered, transformed into a shared frame, voxel-fused, reconstructed with Poisson surface reconstruction, support-cropped, and rendered in Rerun. This pack's screenshot is an unedited capture of that transformed output, not an original dataset image or ground-truth mesh. Retain this attribution, license link and change notice when sharing it. Data rights are based on this dataset-specific CC BY grant, separately from Open3D's software license.

The exact public release ZIP SHA256 is `b94e0146c1d48c5edfc11af71b4af39ffca604485668c55a127c3b43203a6bd5`; its MD5 matches the upstream declaration, and all three PCD member SHA256s match the actual workflow inputs listed in report.json. No customer data is used in the depicted scene.
