# Workbench demonstrations

- [Workbench Studio](workbench-studio/README.md): create portable film projects from your own media, edit briefs and storyboards, and render cached previews and final films.
- [BDD100K demo](bdd100k-demo-walkthrough.md): inspect failure-mode slices in FiftyOne.
- [Workbench access example](team-access.html): an offline, simulated walkthrough of local accounts, allocations, key-backed CLI/API/SDK access, and policy boundaries. It is not a product portal or live infrastructure proof.
- [Validated Lyra result](../workbench/guides/lyra-validated-example.md): generate an offline review from the completed public-capture GPU example, with real source/render playback, depth samples, replay measurement and downloadable YAML. Generated media stays private.
- [Capture-to-scene workflow reference](lyra-splatting-overview.html): synthetic projection illustration and both workflow YAML files. This explainer is separate from the validated native result.
