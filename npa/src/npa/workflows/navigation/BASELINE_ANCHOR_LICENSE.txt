RSL-RL baseline-anchor integration
================================

anchor_update.py adapts PPO.update from RSL-RL v5.0.1:
https://github.com/leggedrobotics/rsl_rl/blob/v5.0.1/rsl_rl/algorithms/ppo.py
Original file SHA-256:
a2d35e7ad7b884c80b7434e7d2ce785a6da1e18d93c96f1179fbd3a208669f8c

Original source header:
Copyright (c) 2021-2026, ETH Zurich and NVIDIA CORPORATION
All rights reserved.
SPDX-License-Identifier: BSD-3-Clause

NPA changes split the supported single-device feedforward update into named
functions, reject unsupported extension modes, and add frozen-baseline KL
before the original backward, clipping and optimizer step. The default
disabled path uses unmodified native PPO. No endorsement is implied.
