# Calibration image attribution

The photographic review sheets derive from NASA Swarmathon competition photographs at Kennedy Space Center. The existing [pinned AprilTag evidence attribution](https://github.com/nebius/nebius-physical-ai/blob/c725a44af7ce222f295b0a54d7866d108c1eb070/docs/workbench/evidence/apriltag-fiducial/ATTRIBUTION.md) records the test media and these derivatives under [CC BY-SA 2.0](https://creativecommons.org/licenses/by-sa/2.0/).

The original workload added expected/detected corner polygons and provenance text, enlarged the exact overlay and added four crops with nearest-neighbor sampling. The shifted negative control deliberately translated detected polygons. Those photographic derivatives are offered under CC BY-SA 2.0. This proof pack preserves the exact image bytes supplied to the VLM; it makes no additional pixel edits. blank.png is the generated white negative control.
