Turnkey operating path / your authorized environment

Configure, preflight, then submit

This form prepares the existing NPA commands for the selected workflow. Run them in your configured checkout. The page makes no API calls and stores no settings.

1. Prepare the input

Stage the selected subset under a worker-readable S3 prefix. Both adapters decode images of at least 64 × 64 and record source/prepared hashes.

2. Resolve dependencies

Use exact scanned operator-private image digests. Shipped example image references cannot run. Verify model access and hosted-model availability.

3. Inspect the handoff

Reopen labels and media. Keep rejected/skipped accounting and visual quality separate from terminal protocol success.

Bash · stop on failed preflight · secret names only

  
Complete npa configure and npa skypilot bootstrap first. Supply credentials through the private NPA credential store or environment. The commands stop on a failed check; a passing check authorizes only its validated dependency.
