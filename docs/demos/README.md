# Workbench demonstrations

- [Workbench Studio](workbench-studio/README.md): create portable film projects from your own media, edit briefs and storyboards, and render cached previews and final films.
- [BDD100K demo](bdd100k-demo-walkthrough.md): inspect failure-mode slices in FiftyOne.
- [Team access example](team-access.html): an offline, simulated walkthrough of local accounts, allocations, key-backed CLI/API/SDK access, and policy boundaries. It is not a product portal or live infrastructure proof.
