    Offboard Alice

    A local denylist blocks new API access, even with a previously valid token. It stops later workflow waves after the next policy check.

    Access is enabled. Existing jobs are not destroyed by removing membership.

    Cloud keys already delivered to a job need separate revocation in cloud IAM. An identity-provider group change alone does not revoke an admitted workflow's group snapshot.

    Administrator setup

    A private configuration maps groups to workspace roles and assigns each person's capacity and storage. These are CLI operations, not a shipped admin UI. 

    npa workbench team storage-create --project PROJECT \
  --endpoint https://objects.example.com --output-dir /private/person
npa workbench team render --config /private/team.yaml \
  --output-dir /private/rendered
npa workbench team enroll --config /private/team.yaml \
  --workspace robotics --cluster east --subject EXTERNAL_SUBJECT
    Reader and admin workspace roles do not unlock another person's runs. Server operators have a separate, trusted cancellation command.

    A service, not another VM.

    The team gateway and private SkyPilot server can live together in one Kubernetes pod. Your existing NPA workflow engine still runs the stages.

    1Existing identity

    Company issuer signs a token. The gateway checks signature, audience, subject, expiry, and groups.

    2Team gateway

    Checks current grants. Binds an immutable run owner, allocation, and storage scope.

    3Private SkyPilot

    Loopback API. Per-person, per-cluster controllers. No direct user access to the server.

    4Enrolled clusters

    Fixed worker identity, GPU quota, restricted RBAC, admission rules, and network policy.

    5Personal storage

    Dedicated cloud principal and bucket. Explicit read-only shared inputs can be added.

    What you operate

    Compute
    One pod, two CPU containers, one replica.
    Durable state
    One persistent volume for the private ownership and runtime ledgers.
    Configuration
    Private policy, enrolled kubeconfigs, and scoped credentials.
    Entry point
    HTTPS gateway; the scheduler has no public Service.
    Clusters
    Explicit connections to each project or cloud's Kubernetes cluster.

  --output-path /private/sky-kubeconfig.yaml
npa workbench team render-service --namespace workbench-system \
  --image private-registry.example.com/team:reviewed \
  --secret team-config --claim team-state \
  --output-path /private/team-service.yaml
